The interactive app at \url{\appurl} runs the same code as the notebook: its calculation module is generated from the
notebook's cells. Users can switch the trend filter off, change the moving-average length, the risk window, the weighting
scheme (risk parity, inverse volatility, equal weights), trading costs, the benchmark, the start year and the asset classes held,
and immediately see cumulative performance, drawdowns, weights and all measures against the benchmark. With default settings
it reproduces Table~\ref{tab:performance}. Source code, dependencies and run instructions: \url{\repourl}.
